# 简历项目描述

**拾途杭州｜AI 行程规划平台｜个人全栈项目**  
技术栈：Vue 3、TypeScript、Pinia、FastAPI、SQLAlchemy、PostgreSQL、Groq、高德地图 API。

负责杭州短途旅行规划产品的前后端设计与实现，构建“自然语言需求—多轮澄清—真实地点消歧—路线规划—预览确认”的完整链路；设计结合结构化输出和工具调用的有界 Agent，将必去地点、返程期限与步行预算交由程序核验，通过换序、跨日分配和可选地点取舍生成差异化方案；基于数据库检查点、SSE 游标续传、版本校验与幂等控制，实现反问后原任务续接及异常恢复，实现条件交互推演、道路核验后的修复解释、独立情景分支比较、攻略原文追溯与批量选点及真实执行回放，配套账号隔离、不可变行程版本、可撤销分享和 CI 自动化回归。

## 有证据时可附加的工程数字

前端 101 项、后端 171 项自动化回归；30 条固定工程任务。它们不是“AI 准确率”，真实模型验收是小样本，不应写成通用成功率或性能 SLA。

## 面试范围

规划范围为杭州 1—3 日、步行或自驾接驳；模型输出建议，程序验证地点和道路约束，用户确认后保存。有界搜索不保证全局最优；实际台阶、营业、停车可用性、票务和景区内步行未实时核验。多轮继续需要已持久化检查点，已确认硬条件改变需重新确认。
